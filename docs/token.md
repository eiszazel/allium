# $ONION and founder interests

$ONION is Allium's associated memecoin—not project equity, a farm deed, or a right to paid data. The original contract is published for inspection; no token deployment, verified contract address, active receiving wallet, or purchase route is claimed here.

## What the original source specifies

The [original Bulb.sol](https://github.com/eiszazel/allium/blob/main/contracts/Bulb.sol) defines an ERC-20 named **ONION Token**, symbol **ONION**, with **18 decimals**. Its constructor mints **1,000,000,000 ONION**—one billion tokens, or 10²⁷ base units—to the supplied constructor recipient.

The recipient is an input to deployment, not a disclosed wallet address or a community distribution schedule. The constructor mint does not establish how tokens would later be allocated, vested, sold, or placed in liquidity.

The source uses OpenZeppelin ERC-20 behavior for transfers and allowances and contains no custom post-construction mint, administrator, fee, or revenue-distribution functions. The reproducible source build uses Solidity **0.8.28** and OpenZeppelin Contracts **5.1.0**. Source inspection or local execution is not an audit, and neither proves that a production contract has been deployed, verified, or safely operated.

Arc is the intended network in the project design. That intention is not a deployed network configuration or an assertion that a testnet market exists.

## What holding the token does not provide

There are no land, LLC-equity, harvest, farm-income, business-revenue, redemption, management, paid-data, or guaranteed-return rights. No rent-funded buyback or holder distribution is promised. A memecoin label and these boundaries do not determine legal classification or settle offering obligations.

There is no public farm raise, target, token-proceeds allocation, fundraising receiver, or funding meter. Token market capitalization is not founder cash; trading volume is not business income.

## Following the founder's money

The proposed farm would be financed with the founder's post-tax cash through a future founder-owned LLC. If actual creator fees or sales of the founder's own token holdings are used, those sources and relevant interests should be disclosed. A founder wallet should not be represented as an unrelated community member. Founder income is not holder income; disclosure of a connection does not create a holder claim.

Distribution, promotion, founder interests, fees, and economic arrangements require jurisdiction-specific review before launch. Token prices can fall sharply or become illiquid irrespective of project progress.
